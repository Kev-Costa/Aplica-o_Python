# Integração Supabase + Z-API

Projeto em Python que lê contatos cadastrados no Supabase e envia mensagens personalizadas pelo WhatsApp usando a Z-API.

Mensagem enviada:

```text
Olá, <nome> tudo bem com você?
```

## Tecnologias

- Python
- Supabase
- Z-API
- python-dotenv
- requests

## Tabela no Supabase

```sql
create table contatos (
  id bigint generated by default as identity primary key,
  nome text not null,
  telefone text not null
);
```

Exemplo:

```sql
insert into contatos (nome, telefone) values
('Kevin', '5582996006874'),
('Maria', '5511888888888'),
('Joao', '5511777777777');
```

## Configuração

Copie o arquivo de exemplo:

```bash
copy .env.example .env
```

Preencha o `.env` com suas chaves do Supabase e da Z-API.

Importante:

- `SUPABASE_URL` deve estar no formato `https://SEU_PROJECT_REF.supabase.co`.
- `ZAPI_CLIENT_TOKEN` deve ser apenas o client token, não a URL completa.
- Use `DRY_RUN=true` para testar sem enviar mensagens reais.

## Como rodar

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Para enviar de verdade, altere no `.env`:

```env
DRY_RUN=false
```
